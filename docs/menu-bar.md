# 顶栏实时监控设计

macOS 菜单栏空间有限，所以顶栏只放最紧凑的读数，细节放在点开的面板里。原生 UI 使用 GPUI Kit 0.9，主窗口里没有监控条，只保留左侧导航。

## 顶栏

- 每个指标是一个独立的 NSStatusItem（CPU / MEM / DISK / TEMP / NET，GPU 与电池可选）。位图宽度按内容定宽，数字变化时不抖动；位图是 Retina 图，默认是模板图、跟随菜单栏明暗，开启彩色后按负载高低着色。项与项之间的距离由「项间距」决定（0–24 pt，默认 10 pt）：系统自带的间距清零，每个位图两侧各留一半。
- 每一项可单独配置：开关、顺序、样式（双行 / 单行 / 趋势）、展示内容（内存：占用率 / 已用量 / 可用量；磁盘：占用率 / 可用量 / 已用量 / 读写速度；温度：CPU 温度 / 最高温度；网络：下载与上传 / 仅下载 / 仅上传；电池：电量 / 剩余时间）。
- 全局可配：指标简称、单位、项间距、是否显示应用图标（至少留一个入口，全部关闭时图标强制显示）、分隔线、彩色、刷新周期、面板里进程排行的条数。设置页顶部有用实时读数画的预览，修改立即生效并持久化。

## 点开的面板

- 一次只展示被点的那个指标，面板左边缘对齐被点的那一项、贴在它所在显示器的菜单栏下沿，右侧太靠边时整体往里收；被点的菜单栏项同时高亮，再点一次收起。其它平台从托盘菜单进入，面板落在主显示器右上角。
- 每个指标一版固定高度的内容：大号读数 + 带标题、平均 / 峰值和时间轴的 LED 历史曲线，CPU 有逐核竖条，内存 / 磁盘 / 温度 / 网络 / GPU / 电池各有对应的卡片。面板不滚动，高度由内容算出，屏幕太矮时进程排行自动减行。
- 放不下的列表（进程、磁盘卷、传感器、网卡）在行末标「全部」，鼠标悬停后在面板左侧或右侧（哪边放得下用哪边）展开二级页面，移开后收起。
- 面板失焦收起，Esc / 关闭按钮收起，固定后失焦保持显示；点进二级页面不算离开。底部可跳转到该指标的完整页面或监控条配置页。

## 数据与性能

- 复用现有硬件快照和监控采样器；顶栏历史按刷新周期单独记录，用于趋势和面板曲线，不受实时监控页暂停 / 清空 / 保留时长的影响。
- 进程采样仅在进程页或 CPU / 内存 / 磁盘面板打开时启动，关闭后停止，旧任务结果不会覆盖新任务。
- 网络面板展示真实的网卡速率，不伪造每进程带宽；CPU 进程百分比以单核 100% 计，可能超过 100%；没有传感器或电池时显示明确的空态。

## 测试

配置兼容与归一化、读数、顶栏位图（宽度稳定、Retina 分辨率）、面板与二级页面的定位（多显示器、屏幕边缘、屏幕高度）有单元测试。
