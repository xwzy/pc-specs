PC Specs Privacy Policy

Last updated: 2026-11-17 · Applies to the Mac App Store edition of PC Specs and to the full edition downloaded from GitHub (Windows, macOS, Linux)

What is on your computer stays on your computer. PC Specs reads and shows your hardware and runtime information locally. It has no account system, analytics SDK or ads, and it never sends your data anywhere on its own. The Mac App Store edition has no network access and is fully offline. The full edition uses the network only in the cases listed in section 5: outgoing requests happen only when you turned the feature on or are looking at the page that uses it, and the local API is reachable from this computer only by default.

1. What do we collect?

Nothing.

  • No telemetry, no usage tracking, no automatic crash uploads
  • No third-party analytics or advertising SDKs
  • No accounts, no sign-in, no device identifiers
  • The Mac App Store edition runs in the macOS sandbox with no network entitlement and contains no networking code

2. What information does the app read?

It reads information about this computer, and only shows, stores and exports it locally:

WhatDetails
Hardware and system informationProcessor, GPU, memory, storage, motherboard, display, battery, peripherals, OS version, hostname, uptime and so on, for the pages that show them. Exports redact MAC addresses, serial numbers and the hostname by default; you can change that in Settings
Live readingsCPU, memory, disk I/O, network speed, GPU usage and similar, for the charts, the menu bar monitor, the monitoring wall and rules
Network informationInterfaces, IP addresses, gateway, DNS, and Wi-Fi details such as signal, channel and link speed, for the Network page and menu bar panel
Full edition only: processes, sensors, apps, startup items, dev environmentRunning processes (name and usage), temperature / fan / voltage / power readings, installed apps and startup items, versions of developer tools. Also only shown locally

3. Which files and folders does the app access?

Only the places you hand to it, or items you explicitly select and confirm:

SituationWhat is accessed
Storage analysisThe disk or folder you choose. A scan reads file names, sizes, modification dates and types. Finding duplicates reads file contents for comparison and keeps nothing afterwards. The Mac App Store edition can only access locations you pick in the open dialog, and remembers them as macOS security-scoped bookmarks purely so you do not have to pick them again
Collector and cleaningItems are moved to the Trash or Recycle Bin (where you can restore them) only after you add them to the collector and confirm. In the full edition, cache cleaning and app uninstalling also list everything first and wait for your confirmation
Disk speed testWhen you start it, a temporary file is written at the test location and deleted right after. The Mac App Store edition only tests the system disk that holds its container
ExportThe location you choose in the save dialog, where a Markdown, JSON, PNG or CSV file is written

The app does not scan your disk in the background and does not read files you did not choose. The Mac App Store edition requests no privacy permissions such as Contacts, Location, Photos, Microphone or Camera; before the first notification, macOS asks whether you allow notifications. On macOS the full edition triggers system prompts when it reads the Documents, Desktop or Downloads folders, and when it manages startup items through System Events. Whether to allow them is up to you.

4. What is stored on your device

WhatFile
Settings: appearance, menu bar items, rules, recently used locations on the Storage page (plus their security-scoped bookmarks in the Mac App Store edition); in the full edition also the webhook address and the local API switchessettings.json
Trend history: the 7-day and 30-day trends in the menu bar panels, keeping only an average and a peak per slot, usually under 100 KB compressedhistory/

Rule trigger logrule_events.json
Storage scan summary: for each scanned location, the paths and sizes of the larger folders from the latest scan, used for “what grew since last time”space/
Disk speed test resultsspeed/

These files live in the app's own pc-specs folder and are all small. On macOS: ~/Library/Application Support/pc-specs (Mac App Store edition: ~/Library/Containers/com.xwzy.pc-specs/Data/Library/Application Support/pc-specs). On Windows: %APPDATA%\pc-specs and %LOCALAPPDATA%\pc-specs. On Linux: ~/.config/pc-specs and ~/.local/share/pc-specs. To remove everything, uninstall the app and delete these folders (Mac App Store edition: delete ~/Library/Containers/com.xwzy.pc-specs).

5. Network use (full edition only)

The Mac App Store edition does none of what this section describes. The full edition does not check for updates and never downloads anything on its own. It uses the network only in these cases:

FeatureWhenWhat is sent, and to whom
Public IP lookupOff by default; only when you click “Fetch now”HTTPS requests to api.ipify.org, ifconfig.co and icanhazip.com in turn; the first valid answer is used. Those services see your IP address; the request carries nothing else about you
Network latency checkOnly while the Network page or the menu bar network panel is open, or when you have configured latency rulesTCP connections to your router, your system DNS server and four public DNS addresses (223.5.5.5, 119.29.29.29, 1.1.1.1, 8.8.8.8) to measure round-trip time. No content is sent; each connection is closed as soon as it is established
WebhooksOnly when you have entered an address and turned on Webhook in a rule, at the moment the rule firesA JSON POST to the address you entered: the rule, the reading, the threshold, rule-related detail (for example the busiest process name), this machine's hostname and the time
Local HTTP data APIOn by default, listening only on this machine's 127.0.0.1:16089 so other devices cannot reach itFor your own scripts and dashboards. You can turn it off in Settings, or choose “Allow LAN access”, in which case any device on the same network can read this computer's hardware information and live metrics, and the per-section endpoints also return the hostname, MAC addresses and serial numbers, with no authentication. Only enable that on networks you trust

Clicking buttons such as “Privacy policy” or “Support” in the app opens pages of this site in your system browser. That visit is one you start yourself.

6. Privacy manifest, Apple and download channels

  • The Mac App Store edition ships a privacy manifest (PrivacyInfo.xcprivacy): no tracking, no data types collected, and it declares four system API categories: file timestamps (to show and compare file dates in the folders you chose), system boot time (to show uptime), disk space (to show capacity and free space) and UserDefaults (to read and write preferences visible only to the app itself)
  • When you download PC Specs from the App Store, Apple processes download-related information under its own privacy policy; we cannot use it to identify you
  • When you download the full edition from GitHub Releases, GitHub processes ordinary request information (such as your IP address, browser type and download time) under its own privacy policy
  • This site is hosted on Cloudflare Pages, which processes ordinary request information when you visit. The site uses no cookies and no analytics scripts

8. Children's privacy

PC Specs does not collect anyone's data, including children's data.

9. Changes to this policy

If the policy changes, this page is updated and the “Last updated” date above is revised. Significant changes to how data is handled are also noted in the app's release notes.
