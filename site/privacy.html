PC Specs 隐私政策

最后更新：2026-11-17 · 适用于 PC Specs 的 Mac App Store 版，以及从 GitHub 下载的全功能版（Windows、macOS、Linux）

你电脑里的信息留在你的电脑里。PC Specs 在本机读取并显示硬件和运行信息，没有账号系统、统计 SDK 或广告，不会主动把你的数据发到任何地方。Mac App Store 版没有网络权限，完全离线；全功能版只有第五节列出的几种情形会用到网络：向外发起的请求，都是你主动打开了对应功能、或正在查看对应页面时才发生，本机接口则默认只对这台电脑开放。

一、我们收集什么？

什么都不收集。

  • 无遥测、无埋点上报、无崩溃自动上传
  • 无第三方分析或广告 SDK
  • 无账号、无登录、无设备标识
  • Mac App Store 版运行在 macOS 沙盒中，没有网络权限，也不含任何联网代码

二、应用会读取哪些信息？

读取的是这台电脑自己的信息，只在本机显示、保存和导出：

内容说明
硬件与系统信息处理器、显卡、内存、存储、主板、显示器、电池、外设、操作系统版本、主机名、运行时间等，用于各个页面的显示。导出时默认隐去 MAC 地址、序列号和主机名，可在设置里改
实时读数CPU、内存、磁盘读写、网络速度、显卡占用等，用于走势图、菜单栏监控、监控大屏和规则判断
网络信息网卡、IP 地址、网关、DNS，以及 Wi-Fi 的信号、信道、速率等连接细节，用于网络页和菜单栏面板
仅全功能版：进程、传感器、应用、启动项、开发环境运行中的进程（名称与占用）、温度 / 风扇 / 电压 / 功耗读数、已安装的应用和启动项、开发工具的版本。同样只在本机显示

三、应用会访问哪些文件和文件夹？

只访问你主动交给它的位置，或者你明确选中并确认的项目：

场景访问内容
存储空间分析你选择的磁盘或文件夹。扫描读取的是文件名、大小、修改时间和类型；查找重复文件时会读取文件内容来比对，比对完不保留内容。Mac App Store 版只能访问你在「选择文件夹」对话框里亲自选的位置，选过的位置以 macOS 的安全作用域书签记住，仅用于下次打开时不必再选
收集箱与清理你把文件加入收集箱并确认后，才会把它们移到废纸篓或回收站（可以从那里恢复）。全功能版的缓存清理、应用卸载也都要先列出清单、由你确认
磁盘速度测试你点击开始后，在测试位置写一个临时文件，测完立即删除。Mac App Store 版只测应用容器所在的系统盘
导出你在保存对话框里选择的位置，写入 Markdown、JSON、PNG 或 CSV 文件

应用不会在后台扫描你的磁盘，也不会读取你没有选择的文件。Mac App Store 版不申请通讯录、位置、照片、麦克风、摄像头等任何隐私权限；发送系统通知时，macOS 会在第一次通知前询问你是否允许。全功能版在 macOS 上读取「文稿」「桌面」「下载」文件夹，以及通过「系统事件」管理启动项时，系统也会弹窗询问，允许与否由你决定。

四、本机保存的内容

内容文件
设置：界面、监控项、规则、存储页最近用过的位置（Mac App Store 版另有这些位置的安全作用域书签）；全功能版还有 Webhook 地址和本机接口的开关settings.json
走势历史：菜单栏面板里 7 天、30 天的走势，每格只留平均值和峰值，压缩后通常不到 100 KBhistory/
流量统计：每天累计的上传、下载字节数，用于「今天、7 天、本月」usage.json
规则触发记录rule_events.json
存储扫描摘要：每个扫描位置最近一次的较大文件夹的路径和大小，用于「相比上次什么变大了」space/
磁盘测速记录speed/
崩溃日志：程序出现内部错误时在本机追加一行（版本、线程、出错位置、错误信息），不会上传，超过大小上限会自动清掉重写crash.log
单实例锁，防止同时开两个窗口（全功能版另有 instance.port，记录本机回环端口，用来唤醒已经在运行的那份）instance.lock

这些文件都在应用自己的配置目录 pc-specs 里，占用的空间都很小：macOS 在 ~/Library/Application Support/pc-specs（Mac App Store 版在 ~/Library/Containers/com.xwzy.pc-specs/Data/Library/Application Support/pc-specs），Windows 在 %APPDATA%\pc-specs 和 %LOCALAPPDATA%\pc-specs，Linux 在 ~/.config/pc-specs 和 ~/.local/share/pc-specs。需要彻底清除时，卸载应用后删除这些文件夹即可（Mac App Store 版删除 ~/Library/Containers/com.xwzy.pc-specs）。

五、联网行为（仅全功能版）

Mac App Store 版没有这一节的任何行为。全功能版不检查更新，也不会自己下载任何东西，只在以下情形用到网络：

功能什么时候发生发送了什么、发给谁
公网 IP 查询默认关闭，只在你点「立即获取」时向 api.ipify.org、ifconfig.co、icanhazip.com 依次发起 HTTPS 请求，取第一个有效的结果。这些服务会看到你的 IP 地址，请求里不带你的其他信息
网络延迟检测只在打开「网络」页或菜单栏的网络面板期间，或者你配置了延迟类规则时向路由器、系统 DNS 服务器和四个公共 DNS 地址（223.5.5.5、119.29.29.29、1.1.1.1、8.8.8.8）建立 TCP 连接来量往返时间，不发送任何内容，连上就断开
Webhook 推送只在你填写了地址、并在规则里打开了 Webhook 之后，规则触发时向你自己填写的地址 POST 一条 JSON：触发的规则、读数、阈值、规则相关的说明（例如占用最高的进程名）、本机主机名和时间
本机 HTTP 数据接口默认开启，默认只监听本机的 127.0.0.1:16089，别的设备访问不到供你自己的脚本和看板读取。在设置里可以关闭，也可以选择「允许局域网访问」，那样同一网络里的设备能读到这台电脑的硬件信息和实时指标，分段接口还会返回主机名、MAC 地址、序列号等，而且没有身份验证，请只在可信的网络里开启

点击应用里的「隐私政策」「技术支持」等按钮时，会用系统浏览器打开本站的页面，这是你自己发起的访问。

六、隐私清单、Apple 与下载渠道

  • Mac App Store 版附带隐私清单（PrivacyInfo.xcprivacy）：不追踪，不收集任何数据类型，只声明用到四类系统接口：文件时间戳（显示和比较你选择的文件夹里的文件时间）、开机时间（显示「已运行时间」）、磁盘空间（显示容量与剩余空间）、UserDefaults（读写仅本应用自己可见的偏好）
  • 你从 App Store 下载 PC Specs 时，Apple 会按照其自身的隐私政策处理与下载相关的信息；我们无法借此识别你的个人身份
  • 你从 GitHub Releases 下载全功能版时，GitHub 会按照其自身的隐私政策处理常规的网络请求信息（例如 IP 地址、浏览器类型和下载时间）
  • 本站托管在 Cloudflare Pages，Cloudflare 会处理访问本站时常规的网络请求信息；本站不使用 Cookie，也没有统计脚本

七、第三方组件

PC Specs 由开源库构建，全部在你的电脑上运行，不含统计或广告：

组件用途
GPUI、GPUI Kit界面渲染
sysinfo 等系统信息库读取处理器、内存、磁盘、网络、电池等信息
ureq + rustls（仅全功能版）第五节中的公网 IP 查询和 Webhook 的 HTTPS 请求
axum + tokio（仅全功能版）第五节中的本机 HTTP 数据接口

八、儿童隐私

PC Specs 不收集任何人的数据，包括儿童的数据。

九、政策变更

如果政策有变化，会更新本页并修改顶部的「最后更新」日期；涉及数据处理方式的重大变化，还会写进应用的更新说明。
