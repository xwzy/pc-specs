pc-specs · local API v1

Read-only HTTP service exposing this machine's PC specs & live metrics. All /api/v1/* endpoints accept POST with a JSON body (may be empty {}) and return JSON.

Endpoints

MethodPathDescription
GET/healthzLiveness check (also POST /api/v1/health)
POST/api/v1/infoLightweight identity (host, OS, app version)
POST/api/v1/metricsLive CPU / memory / network BPS / disk BPS (800ms cache)
POST/api/v1/snapshotFull system snapshot (3s cache). Body: { "include_sensitive": false }
POST/api/v1/hostHostname / username / uptime
POST/api/v1/osOS name / version / kernel
POST/api/v1/cpuCPU model, usage, frequency, topology
POST/api/v1/gpusGPU list
POST/api/v1/memoryRAM total / used / modules
POST/api/v1/storagesStorage devices & SMART
POST/api/v1/motherboardMotherboard / BIOS
POST/api/v1/networkInterfaces, IPs, public IP
POST/api/v1/displaysConnected displays
POST/api/v1/sensorsTemperatures & sensors
POST/api/v1/batteryBattery (laptop only)
POST/api/v1/peripheralsUSB / input devices
POST/api/v1/dev_envLanguages / package managers / editors / containers

Examples

curl -s http://<host>:16089/healthz
curl -s -X POST http://<host>:16089/api/v1/metrics
curl -s -X POST http://<host>:16089/api/v1/snapshot \
     -H 'Content-Type: application/json' \
     -d '{"include_sensitive": false}'

Notes

By default sensitive fields (hostname, username, MACs, serial numbers, public IP) are redacted. Pass {"include_sensitive": true} to /api/v1/snapshot to receive raw values. The service binds to 0.0.0.0:16089; restrict access via your firewall if exposing beyond a trusted LAN.
